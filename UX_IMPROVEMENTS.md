# UX improvement checklist

This is the working checklist for the user-experience improvements identified
in the October 26, 2026 UX review. Mark an item complete only after it is
implemented, verified, and deployed.

- [ ] Make the home page content-led: add clear paths to explore the map,
      sources, clubs, and upcoming events, with a small curated preview.

- [x] Collapse list-page filters by default. Show compact sections with active
      selection counts and a clear-filters action.

- [x] Improve result-card scanning, beginning with events: present date, place,
      period, and a clear past-event state in a consistent order.

- [ ] Reorder club and other entity detail pages around identity first: photo,
      name, era/year range, location, and description before empty/community
      sections.

- [x] Simplify map controls while retaining their capability: keep place search
      visible, group secondary controls, show active-filter chips and result counts,
      and provide a reset action.

- [x] Use readable temporal context consistently, pairing named periods with a
      year range where available.

- [x] Improve empty and loading states with skeletons, helpful explanation, and
      an appropriate next action where possible.

- [x] Refine global search into one unambiguous search affordance that expands
      into filters and results, supports keyboard focus, and can surface recent
      searches.

- [x] Keep map tooltip links keyboard-discernible without restoring a border
      around the resource name; use a subtle non-border focus treatment.

- [x] Add lightweight orientation cues across lists and details: result counts,
      active-filter summaries, and explicit sorting where relevant.
