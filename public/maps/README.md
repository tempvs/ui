# Basemap data

This directory contains low-detail, 1:110m Natural Earth Vector layers used by
the interactive map. They are served as part of the UI's existing static-site
deployment; no external map tile provider is contacted at runtime.

Natural Earth Vector data is in the public domain. Source:
https://www.naturalearthdata.com/about/terms-of-use/

Included layers:

- land
- lakes
- administrative boundary lines (land)
